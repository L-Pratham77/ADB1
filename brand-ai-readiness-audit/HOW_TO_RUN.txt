=================================================================

PREREQUISITES:
--------------
- Python 3.8 or higher.
- Zero external dependencies required!
  (Uses standard Python libraries: urllib, json, html.parser, re, ssl, unittest).


================================================================================
1. RUNNING THE AUTOMATED TEST SUITE (13 UNIT & INTEGRATION TESTS)
================================================================================
To verify all skill checks, agentskills.io format compliance, marketplace manifest,
and end-to-end orchestration against mock fixtures:

From workspace root (ADB1):
    python brand-ai-readiness-audit/test_runner.py

From inside brand-ai-readiness-audit folder:
    cd brand-ai-readiness-audit
    python test_runner.py


================================================================================
2. RUNNING A LIVE AUDIT (ENTRYPOINT SKILL)
================================================================================
The entrypoint skill is "audit-orchestrator", which coordinates all 4 domain skills,
harmonizes overlapping findings, and produces the required audit report.

A. Basic Audit (Prints JSON report directly to terminal):
    python brand-ai-readiness-audit/skills/audit-orchestrator/scripts/orchestrate.py https://example.com

B. Save Results to a JSON File:
    python brand-ai-readiness-audit/skills/audit-orchestrator/scripts/orchestrate.py https://example.com --output my_report.json

C. View as Executive Markdown Summary:
    python brand-ai-readiness-audit/skills/audit-orchestrator/scripts/orchestrate.py https://example.com --format markdown

D. Save JSON and Display Markdown Simultaneously:
    python brand-ai-readiness-audit/skills/audit-orchestrator/scripts/orchestrate.py https://example.com -o audit_report.json --format both


================================================================================
3. RUNNING IN OFFLINE / SANDBOX MODE
================================================================================
If testing in a sandbox environment without internet connectivity, you can provide
local HTML and robots.txt files:

    python brand-ai-readiness-audit/skills/audit-orchestrator/scripts/orchestrate.py example.com --offline-html /path/to/page.html --offline-robots /path/to/robots.txt
